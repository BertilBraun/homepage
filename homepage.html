The repo describes GybeLock as a production MVP web app plus the underlying Python video processing pipeline. It turns shore-shot windsurf footage into rider detections, tracks, stabilization transforms, and an interactive focused-view player.

  • React/Firebase frontend with FastAPI backend and Modal-powered GPU processing.
  • YOLO-based detection and pose tooling with training and optimization runs.
  • Interactive review flow for selecting riders and generating stable playback.

In-progress graph RL system for traffic-signal control. The public repo description frames the current direction as movement-level phase scoring for transfer across arbitrary OpenStreetMap city networks.

  • Built SUMO/TraCI environments with a GATv2 policy controlling junctions jointly.
  • Uses DAgger imitation learning followed by PPO with phased transitions.
  • Current work focuses on lane-to-lane movement scoring for arbitrary OSM junctions.

From-scratch Soft Actor-Critic implementation in pure JAX. The project demonstrates a fully GPU-resident RL pipeline with vectorized environments, GPU replay buffer, neural networks, and training loop.

  • Zero host-device transfers during training.
  • Up to 4096 parallel CartPole environments stepped as one batched operation.
  • Reported 5,248 parameter updates/sec on RTX 3060 with 100% GPU utilization.
